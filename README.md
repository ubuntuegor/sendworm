# Sendworm

Cross-platform desktop app to share files using [Magic Wormhole](https://magic-wormhole.readthedocs.io/en/latest/welcome.html).

## Compatible applications

- [Wormhole](https://github.com/wormhole-app/wormhole) (mobile/desktop)
- [Warp](https://gitlab.gnome.org/World/warp) (desktop)
- [magic-wormhole-cli (Rust)](https://crates.io/crates/magic-wormhole-cli) (desktop)
- [magic-womrhole-cli (Python)](https://magic-wormhole.readthedocs.io/en/latest/welcome.html#installation) (desktop)
